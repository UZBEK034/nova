## Security

The public frontend never contains a private key.

The original local Ganache server and signing backend are NOT included in this public frontend.

## Important

The current contract is deployed on a local Ganache development network (Chain ID 1337).

It is not a public mainnet deployment.

Do not send real funds to the development contract.
